# Combined NorthStar client weather format

## Visual identity: NorthStar Design V2

Use navy #071B2C and white for the main fields; NorthStar blue #104C8E for hierarchy, copper #D2691E for graphic accents and #B85510 for readable copper text. Display typography uses Archivo with an explicit width axis, body copy uses Instrument Sans, and metadata uses IBM Plex Mono. Fonts are bundled locally. The supplied NorthStar star remains intact; the wordmark is live typography.

Pages alternate dense evidence with clear decision summaries. Substantive document text is at least 12 pt. Metadata and locators use smaller supporting type. Tables retain units, dates and source distinctions. Color reinforces labels; it does not replace them.

## Information architecture: weather intelligence

Lead with the hotel preparation decision and executive summary. Follow with property context, a date-qualified compendium review, NWS vicinity guidance, the private track, model views, the New Orleans area wind profile, exposure questions, decisions, scenarios and sources.

Keep official status, private scenario guidance, supporting models and property-specific evidence separate. Source roles are decision weights, not mathematical weights. Display initialization and valid time with model graphics. Distinguish sustained ranges, gusts and probabilities. Preserve the source datum for water levels; never infer property inundation from an unspecified surge figure.

## Client edition

Use plain-language actions and explicit timing. Retain useful uncertainty close to each claim. This requested property edition includes the public hotel address and an attributed historical exterior map. Exclude internal activation records, private access links, raw emails, detailed equipment/security layouts and personal contacts. Named-area guidance cannot establish a particular building's vulnerability.

## Navigation and output

The browser report supports mobile layouts, keyboard navigation, reduced motion, expandable imagery and local checklist state. The PDF retains all scenarios, static charts, source links, linked contents and heading bookmarks. Generated imagery summarizes supplied data; forecast maps and plots remain data-driven. The historical property map is not current condition or hazard evidence. Public model images retain provider attribution.

This task combines the two formats in this deliverable. Installed skill packages are unchanged.
